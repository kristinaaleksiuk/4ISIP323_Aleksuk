### Формула (Метод)
### Итоговая атака = Базовая атака + Атака оружия	(CalculateTotalAttack)
### Критический урон = Итоговая атака × (1 + Крит. урон % / 100)	(CalculateCritDamage)
### Средний урон = Итоговая атака × (1 + Шанс крита % / 100 × Крит. урон % / 100)	(CalculateAverageDamage)
